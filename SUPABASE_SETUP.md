# Supabase leaderboard setup

The site uses Supabase's REST API directly with `fetch`, so no extra JavaScript package is required.

## 1. Create the table

In Supabase, open SQL Editor and run:

```sql
create table public.invitational_entries (
  id bigint generated by default as identity primary key,
  name text not null check (char_length(name) > 0 and char_length(name) <= 80),
  perceived_speed integer not null check (perceived_speed >= 0),
  created_at timestamptz not null default now()
);

alter table public.invitational_entries enable row level security;

create policy "Anyone can read invitational entries"
on public.invitational_entries
for select
to anon
using (true);

create policy "Anyone can add invitational entries"
on public.invitational_entries
for insert
to anon
with check (true);

create policy "Anyone can clear invitational entries"
on public.invitational_entries
for delete
to anon
using (true);
```

## 2. Add environment variables

Create a `.env` file locally with:

```bash
REACT_APP_SUPABASE_URL=https://your-project-ref.supabase.co
REACT_APP_SUPABASE_ANON_KEY=your-supabase-anon-key
```

For the live website host, add those same environment variables in the hosting provider's settings.

## Notes

The admin reset is intentionally a joke: submitting name `admin` with perceived speed `69420` clears the leaderboard. Because this is built into a public website, anyone who knows those values can clear it.
